# 금지 용어 대장

사용자가 "이 말은 쓰지 마라"라고 지시한 표현을 누적한다.
**문서를 넘겨주기 전에 이 대장의 표현이 남아 있는지 반드시 grep 한다.**

```bash
grep -nE '씨앗|큰 흐름|작은 흐름|예산|유의 토큰' "<대상 파일>"
```

자동 치환하지 않는다. 문맥마다 대체 표기가 달라지므로 사람이 문장을 다시 쓴다.

| 금지 표현 | 대체 표기 | 지시일 | 왜 금지되었는가 |
|---|---|---|---|
| 씨앗 (씨앗 확장, 씨앗 노드) | **이웃 확산**, 확산의 **출발점** | 2026-08-15 | 구현 코드의 내부 명칭(seed)을 그대로 옮긴 조어여서 읽는 사람이 뜻을 알 수 없다 |
| 큰 흐름 / 작은 흐름 | **질의 처리 절차** / 그 안에서 호출되는 **하위 절차** | 2026-08-15 | 대화에서 구조를 설명하려고 만든 비유이며 제출 문서의 용어가 아니다 |
| 예산 (본문 예산, 예산 제어) | **컨텍스트윈도우** (붙여 씀) | 2026-08-15 | 실제로 제한하는 것은 모델의 컨텍스트윈도우이지 예산이 아니다 |
| 유의 토큰 | **조사와 불용어를 걷어낸 낱말** (짧게는 「제목 낱말」) | 2026-08-18 | 「유의」가 有意·留意·類義 어느 쪽인지 읽는 사람이 가릴 수 없고, 「토큰」은 코드의 내부 명칭(tokenize)이라 뜻이 전달되지 않는다 |

## 대장에 올리는 기준

- 사용자가 한 번이라도 "그 말 쓰지 마"라고 한 표현은 전부 올린다.
- 코드의 내부 변수명·함수명에서 따온 말(seed, budget, pool, hop 등)은 지시가 없어도 의심한다.
  독자가 코드를 보지 않으므로 뜻이 전달되지 않는다. 우리말 실체어로 바꾼 뒤 쓴다.
- 대화에서 설명하려고 즉석에서 만든 비유는 문서에 옮기지 않는다.
  설명은 대화에서만 하고, 문서에는 그 대상의 이름을 적는다.
